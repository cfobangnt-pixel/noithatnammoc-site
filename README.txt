HUONG DAN DANG WEBSITE NOI THAT NAM MOC TREN GITHUB PAGES

1. Giai nen tep ZIP nay.
2. Dang nhap github.com hoac tao tai khoan.
3. Tao repository moi, vi du: noithatnammoc-site
4. Chon Public va tao repository.
5. Upload cac tep index.html, terms.html, privacy.html len thu muc goc cua repository.
6. Vao Settings > Pages.
7. Trong Build and deployment, chon Deploy from a branch; branch main va folder /(root), sau do Save.
8. Cho GitHub Pages publish website. URL thuong co dang:
   https://TEN-TAI-KHOAN.github.io/noithatnammoc-site/
9. Mo thu index.html, terms.html, privacy.html de kiem tra.

QUAN TRONG VE XAC MINH TIKTOK:
- Tep xac minh phai la tep TikTok cap cho URL property. Tai tep do len thu muc goc cua repository va publish lai.
- Sau khi website duoc publish, mo URL tep xac minh theo dung ten tep TikTok cap. Chi tiep tuc khi URL do hien dung noi dung tep.
- Sau do them/xac minh dung URL property tren TikTok for Developers.
- Khong dung website mau nay de khai thong tin sai. Hay sua noi dung lien he/chinh sach cho dung voi cach ban thuc su van hanh website.
- URL GitHub Pages se khac URL Google Sites cu.
